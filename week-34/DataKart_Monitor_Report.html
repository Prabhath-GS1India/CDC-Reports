Executive Summary

Plain-English overview of DataKart's infrastructure and code-quality health as of 21-08-2026.

What's good

  • Cluster CPU utilization has averaged 9% over the last 7 days — comfortably within normal range.
  • Cluster memory utilization has averaged 32% over the last 7 days — healthy headroom.
  • Database 'dk2db-products' storage is at 46% used — a comfortable level.
  • Database 'dk2db-products-replica1' storage is at 34% used — a comfortable level.
  • Database 'dk2-pgsql' storage is at 20% used — a comfortable level.
  • Database 'dk2-tracedb' storage is at 38% used — a comfortable level.

What needs attention

  • 10 pod restarts due to out-of-memory (OOM) events occurred in the last 7 days — higher than the comfortable range.
  • 2 fatal-level application error(s) were logged in the last 7 days — recommend investigation.
  • SonarQube backlog for the Current Team codebase is 2,419 open of 2,552 issues (95%), all-time — recommend a cleanup sprint.
  • SonarQube backlog for the Hakuna Matata (legacy) codebase is 18,413 open of 19,136 issues (96%), all-time — recommend a cleanup sprint.

Neutral / FYI

  • The Sentry error-tracking export used for this report covers roughly the last 9 days only (394 issues seen); a longer export would be needed for true 14-day/monthly trend comparisons.
  • The weekly database snapshot export's most recent entry predates this report; Database section cards/charts reflect the latest data available in that export, not this week specifically.
