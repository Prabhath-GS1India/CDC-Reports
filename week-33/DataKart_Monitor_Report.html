Executive Summary

Plain-English overview of DataKart's infrastructure and code-quality health as of 15-08-2026.

What's good

  • Cluster CPU utilization has averaged 10% over the last 7 days — comfortably within normal range.
  • Cluster memory utilization has averaged 30% over the last 7 days — healthy headroom.
  • Database 'dk2db-products' storage is at a comfortable 46% used.
  • Database 'dk2db-products-replica1' storage is at a comfortable 34% used.
  • Database 'dk2-pgsql' storage is at a comfortable 20% used.
  • Database 'dk2-tracedb' storage is at a comfortable 38% used.

What needs attention

  • 32 pod restarts due to out-of-memory (OOM) events occurred in the last 7 days — higher than the comfortable range.
  • 2 fatal-level application error(s) were logged in the last 7 days — recommend investigation.
  • SonarQube backlog for the Current Team codebase is large: 1,198 open of 2,967 issues (40%), all-time — recommend a cleanup sprint.
  • SonarQube backlog for the Hakuna Matata (legacy) codebase is large: 18,413 open of 19,136 issues (96%), all-time — recommend a cleanup sprint.

Neutral / FYI

  • The Sentry error-tracking export used for this report covers roughly the last 7 days only (247 issues seen); a longer export would be needed for true 14-day/monthly trend comparisons.
